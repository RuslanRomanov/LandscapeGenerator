# Процедурный генератор 3D-ландшафта

Реализованы этапы 1 и 2.

Этап 1: шум Перлина, 3D-меш из карты высот, wireframe в Pygame, камера.

Этап 2:

- гидравлическая эрозия (симуляция потоков воды, изменяющих рельеф);
- фрактальный шум fBm (несколько октав);
- раскраска по высоте: вода, пляж, трава, скалы, снег;
- экспорт меша в OBJ-файл;
- орбитальная камера в Pygame (вращение мышью, приближение колёсиком).

## Установка и запуск

    pip install -r requirements.txt
    python main.py

Управление в окне:

    левая кнопка мыши + движение   вращение камеры вокруг ландшафта
    колёсико мыши, + / -           приближение и отдаление
    стрелки                        вращение камеры
    Home                           вернуть исходный вид
    W                              переключить закраску / wireframe
    R                              новый случайный ландшафт
    E                              экспорт в OBJ (landscape_seed<N>.obj)
    S                              сохранить скриншот в PNG
    Esc                            выход

Пока камера движется, сцена рисуется упрощённо (прореженная сетка), через
0.15 с после остановки - в полном качестве.

## Параметры командной строки

    --seed N            зерно генератора, одинаковый seed = одинаковый ландшафт (0)
    --resolution N      разрешение карты высот, 8..256 (128)
    --scale X           число ячеек шума вдоль стороны карты (3)
    --octaves N         число октав fBm (5)
    --persistence X     затухание амплитуды по октавам (0.5)
    --lacunarity X      рост частоты по октавам (2.0)
    --erosion N         число итераций эрозии, 0 - выключить (100)
    --water-level X     уровень воды, 0..1 (0.3)
    --height-scale X    множитель высоты рельефа (30)
    --mode solid|wire   режим отображения (solid)
    --line-step N       в режиме wire рисовать каждую N-ю линию (2)
    --width, --height   размер окна (1000 x 700)
    --out-dir ПАПКА     куда сохранять OBJ и PNG из окна (.)
    --export-obj ФАЙЛ   сохранить меш в OBJ
    --save-image ФАЙЛ   сохранить кадр в PNG
    --no-window         не открывать окно (вместе с --save-image / --export-obj)

Примеры:

    python main.py --seed 42 --resolution 192 --erosion 150
    python main.py --seed 7 --export-obj land.obj --save-image land.png --no-window
    python main.py --octaves 1 --erosion 0 --mode wire

## Структура

    main.py                  точка входа, разбор аргументов
    landscape/noise.py       шум Перлина и fBm, карта высот
    landscape/erosion.py     гидравлическая эрозия (модель "труб"), NumPy
    landscape/colors.py      раскраска по высоте и освещение
    landscape/mesh.py        меш из карты высот, нормали
    landscape/camera.py      орбитальная камера, перспективная проекция
    landscape/renderer.py    wireframe и закрашенная поверхность (Pygame)
    landscape/export.py      экспорт в OBJ + MTL + PNG-текстура
    landscape/pipeline.py    конвейер: шум -> эрозия -> раскраска -> меш
    landscape/app.py         окно, события, главный цикл
